# Canvas Forge

**Canvas Forge** is a lightweight and efficient 2D game engine written in C++, designed for both PC and console development. The engine provides developers with a flexible and high-performance platform for creating 2D games.

## Features

- **Cross-Platform**: Supports PC and console platforms.  
- **Lightweight**: Minimal resource usage for maximum performance.  
- **Flexible**: Modular architecture for easy customization and extension.  
- **Efficient**: Built with modern C++ for optimal performance.
